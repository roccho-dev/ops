# handoff result importer

## 課題

- ChatGPT の返答、artifact、verdict、readback JSON を command / claim / evidence に昇格する工程が手作業になりやすい。
- raw ChatGPT prose や readback JSON は、そのままでは canonical state ではない。
- importer がないと、parentActor がどの evidence を根拠に承認・差し戻しするかが曖昧になる。

## 影響

- `transport-read` と semantic approval が混同される。
- artifact hash や verdict source が記録されず、後から検証できない。
- Project handoff の受け取り完了を localizer が判断しづらい。

## close 条件

- readback JSON、artifact path、sha256、threadFunction、expected verdict を入力にして claim/evidence record を生成する。
- inline prose は raw evidence として扱い、accepted claim / approval へ直接昇格しない。
- importer output は localize-readiness-classifier が読める。
