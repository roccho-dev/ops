# project handoff preflight command

## 課題

- ChatGPT Project handoff を始める前に、Project URL、Project Source upload policy、thread bindings、readback plan、artifact contract を機械的に検査する入口が弱い。
- actor が手で確認すると、必要 field の抜けや URL shape の取り違えが起きる。
- preflight がないため、Project handoff ではなく local handoff だけで進んでしまう事故を検出しづらい。

## 影響

- Project Source に渡すべき source / bundle / diff / review input が未送信のままになる。
- `project.source` と thread attachment の境界が崩れる。
- readback / artifact receipt の前提が揃わない。

## close 条件

- `project-handoff-preflight` が JSON で不足 field を返す。
- 検査対象に `projectUrl`、Project Source policy、threadFunction binding、bootstrap artifact、readback interval、expected artifacts を含める。
- 欠落がある場合は `project-binding-missing` または `project-handoff-preflight-failed` として分類する。
