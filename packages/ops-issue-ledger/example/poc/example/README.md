# ops-issue-ledger example / poc / example

This directory is intentionally non-authoritative.

- `src/ops_issue_ledger/` is the library implementation.
- `bin/ops-issue-ledger` is only a wrapper importing the library CLI.
- This example tree may contain malformed or legacy JSONL for demonstrations.
- Workspace discovery must never treat `example/poc/example` as canonical issue input.
