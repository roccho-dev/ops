# ops-cdp-core docs

This directory contains the stable documentation surface for `ops-cdp-core`.

The docs here explain which canonical wrapper or package entrypoint to use.
They should not become a dump of raw conversation history, temporary proof logs,
or long debugging transcripts.

Current boundary:

- `project-transport.md` explains Project Source / Project thread transport.
- profile-runtime facts must point to canonical `ops-cdp-core` behavior and
  issue records, not to deprecated `flakes` or proof worktrees as normal routes.
