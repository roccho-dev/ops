# ops-cdp-core incoming knowledge

This directory is a temporary landing area for CDP, ChatGPT Project, and
profile-runtime knowledge that has not yet been compressed into the canonical
package surface.

Use it only for small indexes, manifests, and pointers to raw proof trees.
Do not copy browser profiles, generated downloads, Project artifacts, nested
Git repositories, or large proof directories here.

Promotion rule:

- durable operational facts go to `../report.jsonl`
- open implementation gaps go to `../../issues/yymmdd.jsonl`
- user-facing runtime guidance goes to `../docs/`
- obsolete raw evidence stays outside canonical `ops`
