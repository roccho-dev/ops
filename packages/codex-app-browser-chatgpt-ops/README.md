# codex-app-browser-chatgpt-ops

Operational helpers for ChatGPT proposal sessions through the Codex in-app
browser surface.

This package is intentionally not a generic browser adapter and not a CDP
adapter. It targets the Codex app browser API exposed as `agent.browsers` and
the `iab` browser.

## Boundary

| Area | Owner |
| --- | --- |
| Chromium CDP, Project Source transport, artifact fetch | `ops-cdp-core` |
| Codex in-app browser session create/rename helpers | `codex-app-browser-chatgpt-ops` |
| GitHub merge approval | out of scope |
| Live ChatGPT mutation in CI | out of scope |

## Main Invariant

The source session is represented by its URL only. PR bodies generated by this
package keep provenance in `Session -> URL` and do not require project IDs,
conversation IDs, or copied title metadata.

## CLI

```sh
codex-app-browser-chatgpt-ops prompt \
  --title "envs: proposal PR template" \
  --task "Create the source session for a proposal PR."
```

```sh
codex-app-browser-chatgpt-ops pr-flow \
  --session-title "envs: proposal PR template" \
  --session-url "https://chatgpt.com/..." \
  --repository roccho-dev/envs
```

```sh
codex-app-browser-chatgpt-ops review-fixture
```

## Browser Entry

Live browser actions are imported from the Codex browser execution context:

```js
const { runInitProjectProposalSession } = await import(
  "file:///path/to/packages/codex-app-browser-chatgpt-ops/lib/codex-app-browser.mjs"
);
```

The live entry creates a project session, renames the sidebar title, captures the
session URL, renders a PR body, and runs the static policy review.
