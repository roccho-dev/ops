# Existing seq/1 Carrier

This closure reconstructs the exact existing maxGraph App from GitHub Git blobs, verifies the fixed App byte identity, opens only the existing `seq/1` `#smap` case in real Chrome, publishes an immutable GitHub Release Carrier, and deploys the same App bytes to `stg-mobile-agent`.

It adds no preset, renderer, layout, codec, backend, or replacement implementation. The public URL is accepted only after stable and deployment-specific Chrome readback pass.
