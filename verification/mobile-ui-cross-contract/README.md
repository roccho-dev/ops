# Mobile ↔ UI cross-contract verification

Runs only against the two supplied repository roots. It proves that the mobile public codec can produce and decompile a chart envelope, the UI projection consumes the validated inspection without copying the mobile reducer, Proposal remains separate from accepted State, explicit publication retains hardened HTTP options, business-specific code does not leak into the generic A2UI runtime, and the retired diagram implementation remains owned by mobile-agent history rather than the current UI tree.
